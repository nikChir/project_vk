# VQA-ru: дообучение визуально-языковой модели для ответов на вопросы по изображениям на русском языке

## О проекте

Проект выполнен в рамках практики на основе открытых данных и моделей организации **deepvk (VK)** — коллекция [Vision-Language Modeling](https://huggingface.co/collections/deepvk/vision-language-modeling-664dd7e4c257cc78e740f6bc).

## Цель

Дообучить (fine-tune) генеративную визуально-языковую модель для корректного ответа на вопросы пользователей по изображениям (Visual Question Answering) на русском языке, используя открытые датасеты организации deepvk, и оценить эффект дообучения по сравнению с исходной моделью.

## Задачи

1. Изучить открытые датасеты и модели коллекции deepvk (Vision-Language Modeling).
2. Провести разведочный анализ данных (EDA): проверить целостность, оценить распределение длины текста, определить бюджет токенов на обучающий пример.
3. Оценить базовую модель «как есть» (baseline) до дообучения.
4. Реализовать пайплайн препроцессинга данных и конфигурацию LoRA-дообучения.
5. Обучить LoRA-адаптер на подготовленной выборке.
6. Сравнить качество ответов модели до и после дообучения на контрольной выборке.

## Ожидаемые результаты

- Дообученный LoRA-адаптер для модели `deepvk/llava-gemma-2b-lora`.
- Количественное и качественное сравнение ответов модели до/после дообучения на фиксированной контрольной выборке.
- Задокументированный, воспроизводимый пайплайн: от анализа данных до обучения, включая описание возникших технических проблем и их решений.

## Используемые данные и модели (открытые источники VK)

| Источник | Назначение |
|---|---|
| [`deepvk/llava-gemma-2b-lora`](https://huggingface.co/deepvk/llava-gemma-2b-lora) | Базовая модель для дообучения (LLaVA-архитектура: CLIP + Gemma-2b) |
| [`deepvk/LLaVA-Instruct-ru`](https://huggingface.co/datasets/deepvk/LLaVA-Instruct-ru) | Основной обучающий датасет — GPT-сгенерированные инструктивные диалоги по изображениям COCO (типы `conversation` и `complex_reasoning`) |

Изображения (COCO train2017 / val2014, на которые ссылаются датасеты deepvk) получены отдельно от официального источника COCO — датасеты deepvk хранят только текстовые аннотации, не сами изображения.

Подробное описание того, как именно использовались данные на каждом этапе (структура, объём выборки, препроцессинг), — в [`REPORT.md`](./REPORT.md).
